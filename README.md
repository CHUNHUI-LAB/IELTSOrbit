# IELTSOrbit

面向不同基础的雅思学习导航：可靠学习资源、可调整的备考路径，以及公开考点与考期信息。

## 运行与部署

此项目是零依赖静态站点。将仓库根目录作为 GitHub Pages 发布目录即可；资源使用相对路径，兼容仓库子路径。无需账户、服务器、API 密钥或数据库。

- `index.html`：页面与无障碍结构
- `assets/`：样式、交互与学习路径逻辑
- `data/catalog.json`：公开资源及来源链接
- `tests/core.test.js`：筛选、数据边界与学习路径测试，运行 `node tests/core.test.js`

## 数据与隐私

只收录公开信息、短摘要及来源链接，不托管试题或教材副本。收藏只保存资源 ID，路径只保存选项，全部留在当前浏览器 localStorage 中，不上传或同步。

考试日期与考位以官方报名系统为准。静态公开日历不代表有可报名名额。站点与 IELTS 考试主办方无隶属关系，不作提分或录取承诺。

首版为人工核验；自动更新未启用。
