# IELTSOrbit

面向不同基础的雅思学习导航：可靠学习资源、可调整的备考路径，以及公开考点与考期信息。

## 运行与部署

此项目是零依赖静态站点。将仓库根目录作为 GitHub Pages 发布目录即可；资源使用相对路径，兼容仓库子路径。无需账户、服务器、API 密钥或数据库。

- `index.html`：页面与无障碍结构
- `assets/`：样式、交互与学习路径逻辑
- `data/catalog.json`：公开资源及来源链接
- `tests/core.test.js`：筛选、数据边界与学习路径测试，运行 `node tests/core.test.js`

## 数据与隐私

只收录公开信息、短摘要及来源链接，不托管试题或教材副本。收藏只保存资源 ID，路径只保存选项，全部留在当前浏览器 localStorage 中，不上传或同步。

考试日期与考位以官方报名系统为准。静态公开日历不代表有可报名名额。站点与 IELTS 考试主办方无隶属关系，不作提分或录取承诺。

首版资料经人工核验；每日检查任务已启用，2026-10-02完成首次有记录的限定范围检查。每条资料仍保留其自身核读日期，不表示所有历史资料已重新核查。

当前共 51 项资料，默认推荐 22 项；另外 29 项是比较、复盘格式或批判性案例，需切换资料范围后查看。B站文章中仅 GY-Seminar 默认推荐。保留 V2EX 首考复盘，核读正文及8条回复，保留作者后来补充的成绩与日程教训；不把该案例作为高分方法的效果证据。

卡片的展开区展示原文核读范围、发表与核读日期、作者起点、投入时长、自报结果、商业关系、评论核读边界，以及可用和不可推广的方法。独立经验页按问题浏览34篇经验，默认全部展示，仍可筛选6篇推荐阅读或28篇参考案例，计划已改为4步向导，考点页改为地点与日期状态优先；资料库与原创练习分别维护。

## 使用入口

首次打开默认展示「从这里开始」。听读写说入口会重置旧筛选并选中对应科目；学习经验入口直达独立备考经验页，先总结，再按问题看案例；默认展示全部34篇，6篇推荐阅读与28篇参考案例保持标签区别并可分别筛选。原有 #library、#path、#exams 地址保持可用。在线练习入口通向现有10道原创练习，不代表真题或完整模考。
