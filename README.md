# IELTSOrbit

面向不同基础的雅思学习导航：可靠学习资源、可调整的备考路径，以及公开考点与考期信息。

## 运行与部署

此项目是零依赖静态站点。将仓库根目录作为 GitHub Pages 发布目录即可；资源使用相对路径，兼容仓库子路径。无需账户、服务器、API 密钥或数据库。

- `index.html`：页面与无障碍结构
- `assets/`：样式、交互与学习路径逻辑
- `data/catalog.json`：公开资源及来源链接
- `tests/core.test.js`：筛选、数据边界与学习路径测试，运行 `node tests/core.test.js`

## 数据与隐私

只收录公开信息、短摘要及来源链接，不托管试题或教材副本。收藏只保存资源 ID，路径只保存选项，全部留在当前浏览器 localStorage 中，不上传或同步。

考试日期与考位以官方报名系统为准。静态公开日历不代表有可报名名额。站点与 IELTS 考试主办方无隶属关系，不作提分或录取承诺。

首版资料经人工核验；每日检查任务已启用，首次定时执行结果尚待验证。

## 资料与经验

当前共 28 项资料，默认推荐 20 项；另外 8 项是比较、复盘格式或批判性案例，需切换资料范围后查看。B站文章中仅 GY-Seminar 默认推荐。最新加入 V2EX 首考复盘，核读正文及8条回复，保留作者后来补充的成绩与日程教训；不把该案例作为高分方法的效果证据。

卡片的展开区展示原文核读范围、发表与核读日期、作者起点、投入时长、自报结果、商业关系、评论核读边界，以及可用和不可推广的方法。新独立经验页按问题浏览12篇经验（5篇默认推荐、7篇主动选择的参考），计划已改为4步向导，考点页改为地点与日期状态优先；原始资料数据与原创练习不变。

## 使用入口

首次打开默认展示「从这里开始」。听读写说入口会重置旧筛选并选中对应科目；学习经验入口直达独立备考经验页，先总结，再按问题看案例；默认5篇推荐阅读，7篇参考案例需主动选择。原有 #library、#path、#exams 地址保持可用。在线练习入口通向现有10道原创练习，不代表真题或完整模考。

## 2026-10-01 引导式学习流程

- 学习资料先按听、读、写、说呈现重点、错因与建议顺序；站内方法详情之后才连接资源摘要和原文。来源、费用等筛选默认折叠
- 新增独立 `#experience` 备考经验页：先读跨案例总结，再按问题看过程。12篇个人经验中默认5篇，7篇明确参考案例需主动选择；不把全部28项资源中的8项参考与个人经验数量混淆
- 学习计划为4步向导，未知可跳过；生成3项今日任务与可移动的7天安排。时间分配为编辑建议，不估分，不替考生决定报名日期
- 考点先展示杭州4个旧公开名录地点与日期缺口，再展示政策详情与报名外链。未新增日期；全国公开考期表不等于杭州各地点当期可报名场次
- 旧 `#library`、`#path`、`#exams` 和已有收藏/分数选项可继续使用；新增单科及资源详情hash支持站内跳转与返回
- 浏览器保存仍只在本地；失败时保留当前页面可用性。原有10道原创阅读练习保持原状，不是真题或完整模考
